# BLACKLISTED landing — agent instructions

Static Astro site (SIDSTACK tech tier T1). No backend; nothing server-side lives in this tree.

## Directory schema (BASE-RULES §1 — keep it)
- `frontend/` — this tree: the whole site, client-only. A future API goes in a sibling `backend/`, never in here.
- `src/pages/` — one route per file; pages only import and order sections.
- `src/sections/` — page sections (Loader, Nav, Hero, Blacklist, Visit, Footer).
- `src/components/` — reusable atoms (GlassButton, HeroDock, AsteriskMark, LegalPage).
- `src/lib/` — all behaviour (frames, scrub, loader, chromeSpin, dissolve, blacklist, loop, touchCursor, smooth). Sections never fetch.
- `src/data/` — content and constants (categories, site, traced asterisk path).
- `src/scripts/main.ts` — the single entry that wires lib to the DOM.
- `src/styles/global.css` — Tailwind v4 + the palette tokens from `.planning/palette.json`. No other colours. No authored `style=""`.
- `public/` — hero frames (`frames/d` desktop, `frames/m` mobile), self-hosted OFL fonts, models, media, the vendored Vessels Glass kit (+ NOTICE).

## Design law
Palette, fonts, glass and motion come from `../.planning/` (MASTER-DESIGN-IDENTITY.md and its specs). Glass only via the Vessels Glass kit (`data-vg`).

## Notes
Hero frames are generated by `media/hero-01/dewatermark.py` (marks removed per frame). The chrome spin is rendered by `media/3d/logo/render_spin.py` (Blender, 72 frames).
